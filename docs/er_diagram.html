EV Service Management — ER Diagram

Database: ev_service_db — 4 relational tables

users → vehicles

One user can own many vehicles. The vehicles.user_id foreign key links each vehicle to exactly one owner. Deleting a user should cascade to their vehicles.

vehicles → service_requests

One vehicle can have many service requests over time. The service_requests.vehicle_id foreign key enforces referential integrity.

service_types → service_requests

One service type can appear in many service requests. The service_type_id FK guarantees every booking references a valid service type.

DBMS Demonstration SQL Queries

1. All vehicles owned by a specific user
SELECT v.vehicle_id, v.manufacturer, v.model, v.registration_number, v.purchase_year
FROM vehicles v
JOIN users u ON v.user_id = u.user_id
WHERE u.email = 'user@example.com';
2. All pending service requests with vehicle + user info (JOIN)
SELECT sr.service_id, u.full_name, v.manufacturer, v.model,
       st.service_name, sr.requested_date, sr.status
FROM service_requests sr
JOIN vehicles v ON sr.vehicle_id = v.vehicle_id
JOIN users u ON v.user_id = u.user_id
JOIN service_types st ON sr.service_type_id = st.service_type_id
WHERE sr.status = 'Pending'
ORDER BY sr.requested_date ASC;
3. Count services booked per vehicle (GROUP BY)
SELECT v.manufacturer, v.model, v.registration_number,
       COUNT(sr.service_id) AS total_services
FROM vehicles v
LEFT JOIN service_requests sr ON v.vehicle_id = sr.vehicle_id
GROUP BY v.vehicle_id, v.manufacturer, v.model, v.registration_number
ORDER BY total_services DESC;
4. Count completed services
SELECT COUNT(*) AS completed_services
FROM service_requests
WHERE status = 'Completed';
5. Full 4-table JOIN for reporting
SELECT u.full_name, u.email, v.manufacturer, v.model,
       v.registration_number, st.service_name,
       sr.requested_date, sr.status, sr.issue_description
FROM service_requests sr
JOIN vehicles v       ON sr.vehicle_id      = v.vehicle_id
JOIN users u          ON v.user_id          = u.user_id
JOIN service_types st ON sr.service_type_id = st.service_type_id
ORDER BY sr.created_at DESC;
